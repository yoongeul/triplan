# 두 가족 여행 체크리스트

## 들어간 기능
- `계획 / 일정` 탭 분리
- 일정 날짜·시간·장소 기록
- 같은 여행 코드를 사용하는 두 가족의 체크리스트 공유
- 카테고리 추가·이름 수정·삭제
- 체크리스트 항목 입력, 수정, 삭제
- 완료 체크
- 참여자 또는 가족을 자유롭게 추가·삭제
- 담당자는 선택 사항이며 등록된 참여자 중에서 선택
- 예약 필요 항목 표시
- 예약 완료 여부, 예약일시, 예약처, 예약번호, 예약 메모 기록
- 예약 확인 화면·티켓·영수증 사진 선택 및 붙여넣기
- 모바일 화면 대응

## 바로 실행
`index.html`을 브라우저로 열면 로컬 데모 모드로 작동합니다.

## 두 가족 실시간 공유 설정
1. Supabase 프로젝트를 만듭니다.
2. `supabase-schema.sql`을 SQL Editor에서 실행합니다.
3. `app.js` 맨 위의 값을 입력합니다.

```js
const SUPABASE_URL = "프로젝트 URL";
const SUPABASE_ANON_KEY = "anon public key";
```

4. GitHub Pages, Netlify 또는 Vercel에 올립니다.
5. 두 가족이 같은 주소에서 같은 여행 코드를 입력합니다.
